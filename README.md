## Python Data Structures & Algorithms (DSA)
Welcome to the Python-DSA repository! This project serves as a comprehensive collection of Data Structures and Algorithms implementations in Python. It is designed to track progress, master core concepts, and build a solid foundation for coding interviews and competitive programming.
## 🚀 Repository Structure
The codebase is organized by data structure types. Each folder contains individual problem directories with their respective Python implementations (main.py).
## 📂 1. Arrays
This section covers foundational array manipulation, searching, sorting, and two-pointer techniques.

* Basic Operations
* Arrays - Largest, Smallest, Linear Search, Insertion, Appending, Deleting at beginning and End
   * REMOVE DUPLICATES
* Rotations & Rearrangements
* Left Rotation of the Array at k-position
   * Right Rotation of an array K position
   * Move Zeros
   * Move Negative Numbers to One Side
   * Reverse an Array - All Methods
* Searching & Statistics
* Second Largest Element in an array
   * Find the Missing Number
   * Find the Majority Element
* Two-Pointer Technique
* Two Pointer - Pair Sum
   * Two Pointer - Palindrome
* Set Operations & Subarrays
* Union of Two Arrays
   * Intersection of Two Arrays
   * Kadane's Algorithm - Maximum Subarray Sum

## 🛠️ Getting Started## Prerequisites
Make sure you have Python 3.x and Git installed on your system.
## Installation
Clone this repository to your local machine:

git clone https://github.com/PavaniGudupu/Python-DSA.git
cd Python-DSA

## Running the Code
Navigate to any problem directory and execute the script using your terminal:

cd "Arrays/Kadane's Algorithm - Maximum Subarray Sum"
python main.py
